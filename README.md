# AllFixDoc – translations

User interface texts and user guide of **AllFixDoc** (PDF & Office reader/editor for Android) in 14 languages.
The app's source code is not public.

- `i18n/gen_strings.py` – English + Turkish source texts
- `i18n/translations/*.py` – other languages
- `guide/` – user guide texts

Found a wrong translation? Open an issue or a pull request.
